# 网站业务候选提取与原文证据完成记录

日期：2026-08-31

状态：用户批准范围的本地实施与回归已完成；未推送、未部署。不是完整 V22-032、GBP 实质对齐或 v2.2 发布。

## 已交付

- 独立纯入口 `app.report_v22.site_business_facts.build_site_business_facts`；输入只包含最小案件上下文、客户 site 快照及可下调上限。没有网络、时钟读取、UUID 分配、持久化或 LLM 调用。
- 严格重验模型和字典内嵌套对象，校验完整载荷摘要、案件/站点/版本/时间及深度页面归属。来源缺失、过期、不健康或明确身份不符时不提取候选。站外重定向、缺 HTML、未采样、未检查与错误响应各自记录原因，不伪装成没有业务信息。
- 从保存 HTML 的白名单 JSON-LD 商家记录、电话链接、address 元素与精确标签提取名称、地址、电话和服务区域。支持对象/数组/@graph、contactPoint、地址组件和服务区域名称；不提升任意嵌套 author/publisher，不加载引用或远程上下文。
- 保留多实体、多门店、多号码及区域短语；不选主值、不判冲突、不做 GBP 比较。结构化记录的 declared_entity 只表达记录归属，不表示确认客户；DOM 及站外身份线索保持 unresolved。
- 原值保留 Unicode、大小写和首尾空格；只对 DOM 执行实体解码、文本拼接及 br 换行。结构化地址不合成伪原文，每个实际组件分别生成证据。隐藏和非正文子树不参与 DOM 候选，嵌套联系组不拼成外层标签的业务值。
- 每个候选保留实际请求/响应 URL、来源快照/时间、HTML 字符区间、JSON Pointer/记录位置或 DOM 路径、实际原文切片与截短标记。原始响应字节摘要只引用；另算解码 HTML 摘要，不冒称重验原始响应字节。
- sf_/ev_ 确定性编号；同一逻辑观察合并全部唯一位置，不同页面、实体记录、地址值组保持隔离。独立复核候选、证据、追踪和页面字段引用，拒绝跨页、跨字段、跨组件借值与 ID 冲突。
- 页级 parsed/partial/not_checked/parse_failed 与字段 observed/not_observed/not_checked、归属状态分开；局部坏块不抹掉有效通道。缺少内容不制造 Evidence。固定的未确认主体/规则受限声明始终保留，证据说明最多 20 项，完整说明留在候选与结果。
- 输入/输出、HTML 字节/深度/节点、JSON 块/字节/深度/节点、字段数组、候选、证据及位置均有上限。超限整体失败，不返回截断候选；错误和非法模型序列化警告不回显载荷。

新增 `scripts/export_v22_site_business_fixtures.py`。后端固定虚构输入经过真实新入口生成；前端只接收 EvidenceItem 数组和字节哈希 manifest，不接收原始 HTML、内部候选、Finding 或伪造完整报告。

## 未变更与后续

仅在现有内部 EvidenceSelector 增加 site_business_field 类别，没有新增其默认字段。冻结报告/API/Schema/TypeScript 类型、旧 fixtures、v2.1、采集器、数据库、配置、worker/executor 与前端运行时均未变更。旧 build_evidence_index/build_public_findings 不自动消费新候选，四项 GBP 检查仍维持原未检查逻辑。

V22_ANALYZE_ENABLED、V22_PREFLIGHT_ENABLED、V22_COMPETITOR_DISCOVERY_ENABLED 默认仍为 false，worker 仍使用 UnavailableV22Executor。本轮没有生产接线、真实供应商采集、浏览器渲染/UI/PDF 验收或发布。

调用方仍须保证真实租户、案件及来源授权；快照标签不是本模块可以证明的真实商家身份。候选信息来自站点声明，不能当作已确认客户或主门店。

下一阶段需要明确客户实体/门店选择、电话和地址比较、服务区域关系，再显式接入网站与 GBP 四项实质对齐。多值本身不构成冲突或评级。真实公开 GBP 采集、其余语义规则、Actions 与完整报告 UI/PDF 仍是后续工作。
