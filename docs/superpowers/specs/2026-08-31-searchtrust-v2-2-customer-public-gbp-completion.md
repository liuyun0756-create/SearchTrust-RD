# 客户公开 GBP 快照与证据离线接入完成记录

状态：已完成用户批准范围的本地实施与回归；未推送、未部署，未接入生产执行器。不是完整 V22-032 或 v2.2 发布。

## 已交付

- 纯入口 `app.report_v22.public_gbp_snapshot.build_customer_public_gbp_snapshot`，严格区分独立确认参考、请求目标、实际返回记录及推导身份。输入/输出均为 1 MB 上限，允许下调；不读取时钟、不联网、不生成 UUID、不持久化。
- 六项字段均要求显式 state/value，未知与返回空分开；保留真实 false 和原始文字空格，拒绝空白或超长强标识。实体键按 place_id/data_id/cid 排序，不转换类型或大小写。
- 身份规则版本 customer_public_gbp_identity_v1：同类型强标识冲突优先；无可比标识待确认；有共同匹配标识后复核实际网站域名。名称、电话、地址、区域差异不用于身份门槛。失败请求必须没有业务字段。
- 新内部 public_gbp 来源与客户确认参考接入证据构建器。独立验证 case/site/确认时间、目标、完整参考摘要、完整载荷校验和、采样/到期时间及身份/健康标签；载入快照重新构建，不信任伪造 matched。显式期限不得超过完成时间后 30 天，这是工程边界，不代表完成第三方政策核验。
- 新公开分支只接受 prospect，同一构建最多一份不同公开快照；完全相同输入去重，全局 UUID 冲突先于适配器拒绝。过期、不可用、身份冲突/待确认只产生来源覆盖，不能输出业务字段。
- 实际字段、实际返回标识和 URL 生成可追踪标量证据；不把请求/确认资料冒充响应。缺少响应 URL 时不回填。返回空对应 empty，未返回/不支持对应 partial；重复区域值合并全部物理路径。
- 每条公开证据固定声明非授权 GBP Performance 数据，即使限制说明溢出也保留该声明；完整来源说明与身份/失败原因保留在内部摘要和相关检查中。错误和非法模型序列化警告不回显载荷。
- 内部摘要及缺口新增 gbp_origin，公开资料与历史第一方 GBP 未连接缺口可以共存；公开缺口与实际公开来源互斥。无快照只记元数据，不虚构 Evidence 或 UUID。
- 四项 GBP 检查仍为 not_checked，按缺资料、来源不合资格、字段未取得、比较尚未实现分别记录原因，并检查来源、快照、字段与引用。没有生成 GBP Finding、竞品比较或八层评级。

## 兼容与可信边界

冻结 EvidenceItem.source_type 仍为 gbp，公开/第一方由内部 kind、来源摘要、选择器及说明区分。没有新增冻结根字段或选择器默认字段，沿用旧证据编号算法；六条已实施 Finding 规则及编号保持不变。

调用方仍须验证租户权限、真实快照归属、供应商响应真实性与用户确认。纯构建器只接受可信调用方提交的规范化记录，不是供应商解码器，也不能证明记录已存储。

所有实际业务文字在新分支保留原值；旧模型的默认去空格行为与旧分支输出不变。内部摘要/缺口增加可选来源用途字段是本轮明确允许的内部接口变化，不进入冻结报告。
